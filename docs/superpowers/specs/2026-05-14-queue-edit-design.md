# 队列编辑功能设计

## 背景

现有应用有两个独立页面：
- **供应商页面**：显示供应商卡片 + 模型列表，点击模型"+"添加到新建队列的缓存区
- **队列页面**：只能查看、拖拽排序、删除项，无法向现有队列添加新模型

问题：编辑队列需要从供应商模型列表挑选，但两个功能分散在不同页面，用户需要来回切换。

## 解决方案

合并供应商页面和队列页面为一个页面，队列列表作为顶部标签栏，供应商卡片作为主要内容区，编辑队列通过右侧滑入面板实现。

## 页面布局

```
┌─────────────────────────────────────────────────────────────┐
│  顶部状态栏                                                 │
├─────────────────────────────────────────────────────────────┤
│  队列标签栏（约 40px 高）                                    │
│  [默认队列(当前)] [队列2] [队列3] [+ 新建]                    │
│  ↑选中弹出编辑面板                                          │
├─────────────────────────────────────────────────────────────┤
│  供应商卡片网格（剩余空间）                                  │
│  ┌─ OpenRouter ──┐  ┌─ LongCat ───┐  ┌─ 自定义 ───┐        │
│  │ ...           │  │ ...         │  │ ...         │        │
│  └───────────────┘  └──────────────┘  └──────────────┘       │
│                                             [编辑面板滑入→]  │
└─────────────────────────────────────────────────────────────┘
```

## 队列标签栏

- **横向排列**：队列名作为标签页，最右侧是"+ 新建"按钮
- **默认队列**：显示"(当前)"标记，或用不同颜色/样式区分
- **选中交互**：点击标签 → 右侧弹出编辑面板
- **高度**：约 40px，紧凑设计
- **样式**：选中标签使用 primary 颜色高亮，未选中标签使用 muted 颜色

## 编辑面板

右侧滑入面板（280px 宽），复用现有 DraftQueuePanel 的结构和样式。

### 新建队列模式

- 标题：显示"新建队列"
- 队列名输入框：默认填充"队列 N"（N 为当前队列数量 + 1）
- 队列项列表：初始为空，显示提示"点击左侧模型添加"
- 底部按钮："取消" | "保存创建"

### 编辑队列模式

- 标题：显示"编辑队列"
- 队列名输入框：显示当前名称，可修改
- 队列项列表：显示当前队列内容，可拖拽排序、可删除单项
- 底部按钮："取消" | "保存修改"
- 特殊按钮：
  - "设为当前"按钮（仅非默认队列显示）
  - "删除队列"按钮（仅非默认队列显示，点击后二次确认弹窗）

## 交互逻辑

### 手动保存机制

所有改动（改名、添加模型、删除模型、拖拽排序）暂存面板内部状态：
- 点击"取消" → 关闭面板，放弃所有改动，恢复原状
- 点击"保存" → 调用 `updateQueue` API，保存后关闭面板

### 添加模型流程

1. 点击队列标签 → 弹出编辑面板
2. 点击供应商卡片上的模型"+"按钮 → 模型添加到面板内的队列项列表
3. 改动暂存，未保存
4. 点击"保存" → 所有改动（包括新增模型）一起保存

### 新建队列流程

1. 点击"+ 新建"标签 → 弹出编辑面板（新建模式）
2. 输入队列名、添加模型
3. 点击"保存创建" → 调用 `createQueue` + `updateQueue`，创建并保存队列
4. 新队列自动添加到标签栏，并设为选中状态

### 删除队列流程

1. 编辑模式下点击"删除队列"按钮
2. 弹出确认对话框："确定删除队列 xxx？"
3. 确认 → 调用 `deleteQueue` API，关闭面板，标签栏移除该队列
4. 自动选中下一个队列（或默认队列）

## 代码改动

### 文件变更

1. **删除 `QueuePage.tsx`**：队列页面不再独立存在
2. **修改 `Sidebar.tsx`**：移除"路由队列"菜单项，只保留"供应商"、"日志"、"设置"
3. **修改 `ProvidersPage.tsx`**：
   - 添加队列标签栏组件
   - 修改编辑面板逻辑（支持新建/编辑两种模式）
   - 点击模型"+"按钮时，将模型添加到当前选中队列的编辑面板（而非固定的新建缓存区）
4. **修改 `DraftQueuePanel.tsx`**（或重命名为 `QueueEditPanel.tsx`）：
   - 支持新建/编辑两种模式
   - 添加"设为当前"、"删除队列"按钮
5. **修改 `App.tsx`**：
   - 移除队列页面的路由逻辑
   - 管理选中队列状态
   - 处理新建/编辑/删除队列的业务逻辑

### 状态管理

在 `App.tsx` 中新增状态：
- `selectedQueueId: string | null` — 当前选中的队列 ID（用于编辑）
- `editPanelMode: "new" | "edit" | null` — 编辑面板模式
- `editPanelItems: QueueItem[]` — 编辑面板内的队列项（暂存）
- `editPanelName: string` — 编辑面板内的队列名（暂存）

## 边界情况

- 队列列表为空时：标签栏只显示"+ 新建"，默认选中状态为 null
- 默认队列被编辑时：不显示"删除队列"按钮，但可以改名和修改内容
- 编辑面板打开时切换到其他页面：关闭面板，放弃未保存的改动
- 队列名冲突时：保存时检查，提示用户修改名称
